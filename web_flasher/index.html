⚡ Прошивка SandiSolar 6.5 Pro (ESP32-S3-N16R8)

Онлайн-інсталятор прошивки через браузер (Google Chrome, Microsoft Edge або Opera) без встановлення додаткових програм.

  1. Підключіть плату ESP32-S3-N16R8 кабелем USB Type-C до комп'ютера (рекомендовано у порт UART / COM або USB).
  2. Натисніть кнопку нижче та оберіть USB-порт плати у спливаючому вікні браузера.
  3. Позначте галочку Erase device (при першій прошивці) та натисніть Install.
